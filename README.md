# RP Stamina

Выносливость для ролевого сервера на **Minecraft 1.20.1 (Forge)**. Мод семейства RP: требует
[RP Core](https://github.com/faygoLover/RP-Core), остальные моды семейства — по желанию.

## Возможности
- **Полоска выносливости** — элемент общего HUD, двигается в редакторе `/rphud`.
- **Что тратит выносливость** (все цены в конфиге):
  - бег, прыжки, плавание, подъём по лестнице;
  - добыча блоков (с учётом твёрдости);
  - удары и размахи в ближнем бою: первый размах за 5 секунд бесплатный, дальше дороже;
  - лук, арбалет, трезубец, щит.
- **Восстановление:** после траты — пауза, потом скорость плавно растёт. Быстрее всего — во сне, затем сидя,
  стоя и пригнувшись, медленнее всего — на ходу.
- **Измотан (выносливость кончилась):** замедление, бег запрещён до порога, медленнее добыча, слабее удары.
- **Броня:** чем тяжелее, тем дороже движение. Можно выключить.
- **Голод и жажда:**
  - ванильный запрет бега при голоде ≤ 6 снят (своей проверкой бега на клиенте, сытость не подменяется);
  - действия не тратят насыщение; голод тратится понемногу от жизни и за каждое восстановление выносливости;
  - еда сама по себе отдых **не ускоряет**; голод и жажда его замедляют (берётся худшее);
  - с [RP Culinary](https://github.com/faygoLover/RP-Culinary) голод и жажду ведёт она и берёт калории за
    восстановленную выносливость (событие RP Core).
- **Восстанавливающие предметы** (датапак): вода (слабо) и стимуляторы — кофе ускоряет восстановление на время,
  потом «отходняк». Привыкание при частом употреблении. Обычная еда выносливость не восстанавливает.
- **Особенности RP Perks:** Второе дыхание (раз в час при нуле — половина запаса), Быстрый отдых (сидя вдвое
  быстрее). Телосложение и возраст из анкеты тела меняют запас и восстановление.

## Установка
1. Minecraft **1.20.1**, **Forge 47** или новее, Java 17.
2. Положите в папку `mods` **на сервере и у каждого игрока** `rpcore-<версия>.jar` и `rpstamina-<версия>.jar`.

## Команды (ГМ, права 2)
| Команда | Что делает |
|---|---|
| `/rpstamina get [игрок]` | текущая выносливость |
| `/rpstamina set <игроки> <число>`, `/rpstamina add <игроки> <число>` | выставить или добавить |
| `/rpstamina refill [игроки]` | восстановить полностью |
| `/rpstamina reload` | перечитать папку `config/rpstamina_custom` |
| `/rpstamina export_defaults` | выложить данные по умолчанию в `config/rpstamina_custom` для правки (отладочная) |
| `/rpstamina debug [игрок]` | подробности о тратах и восстановлении (отладочная) |

Отладочные команды работают, только если в `config/rpcore-common.toml` включено `debug_commands`.
Редактор HUD — `/rphud`, все команды семейства — `/rpcore commands` (команды RP Core).
Время RP (`/rptime`, RP Core): «стоп» выносливость не трогает; `/rptime sleep` — выносливость полная,
`/rptime skip` — восстанавливается как стоя; привыкание к предметам и «отходняк» проходят за это время.

## Настройки
- `<мир>/serverconfig/rpstamina-server.toml` — вся механика: цены действий, восстановление, броня, голод.
- `config/rpstamina-client.toml` — ширина и высота полоски.
- **Предметы, блоки, оружие** — датапаком (`data/<ns>/rpstamina/<категория>/*.json`, работает `/reload`) или файлами
  в `config/rpstamina_custom/`: папка создаётся сама при первом запуске, внутри `README.txt` с форматом. Категории:
  `consumables` (предметы), `groups` (привыкание), `use_costs` (луки, арбалеты и т. п.), `weapons` (что считать
  оружием или игнорировать), `blocks` (добыча).

Пример — вода восстанавливает выносливость:
```json
{
  "item": "minecraft:potion",
  "nbt": { "Potion": "minecraft:water" },
  "instant": 120, "instant_ticks": 200,
  "passive_per_tick": 0.03, "duration_ticks": 400,
  "group": "water"
}
```

## Для сборщиков сборки: атрибуты
Выносливость меняется обычными атрибутами (модификаторы, команда `/attribute`, перки RP Perks):

| Атрибут | По умолчанию | Что меняет |
|---|---|---|
| `rpstamina:max_stamina` | 1000 | максимум |
| `rpstamina:regen_multiplier` | 1.0 | скорость восстановления |
| `rpstamina:cost_multiplier` | 1.0 | общий расход (0 — ничего не тратится) |
| `rpstamina:move_cost_multiplier` | 1.0 | бег, прыжки, лестницы |
| `rpstamina:swim_cost_multiplier` | 1.0 | плавание |
| `rpstamina:mine_cost_multiplier` | 1.0 | добыча |
| `rpstamina:melee_cost_multiplier` | 1.0 | удары и размахи |
| `rpstamina:armor_burden` | 1.0 | влияние веса брони (0 — броня не мешает) |

## Совместимость
- **RP Perks** — перки меняют максимум, восстановление и расход; нагрузка качает навыки Сила и Форма.
- **RP Culinary** — голод и калории.
- **RP Medicine** — переноска раненого тратит выносливость; травмы и состояние тела влияют на неё.
- Огнестрел и предметы других модов не трогаются, пока не перечислены в данных.
